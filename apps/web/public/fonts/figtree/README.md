# Figtree Font Asset

The production site self-hosts the Latin subset of Figtree as a variable WOFF2 file for weights 400 through 700.

- Family: Figtree
- Source stylesheet: https://fonts.googleapis.com/css2?family=Figtree:wght@400..700&display=swap
- Font file source: https://fonts.gstatic.com/s/figtree/v9/_Xms-HUzqDCFdgfMm4S9DQ.woff2
- Upstream metadata: https://github.com/google/fonts/tree/main/ofl/figtree
- Retrieved: 2026-09-30
- License: SIL Open Font License 1.1, included as `OFL.txt`

The downloaded file is unmodified. Its filename is normalized locally to describe the supported subset, axis, and style.
